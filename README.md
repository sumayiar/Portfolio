## Implementation

- `index.html` contains the portfolio content and semantic section structure.
- `style.css` contains the responsive pastel-to-ocean theme, night mode, navigation, cards, and motion styling.
- `script.js` manages the theme toggle and section reveals.
- `just-cook-it-behavioral-ux-analysis.html` contains the deeper Just Cook It case study.
- `assets/` contains project mocks, team photography, credential files, and section icons.

## Run Locally

From this directory, serve the files with any static web server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
